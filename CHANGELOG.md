### Added - 2026-10-21 (Task M1: Trades Backend)
- **Trade Backend: Server-side item ownership and user-to-user trade state machine** - Implemented database-driven trade system with NO hard-coded limits. All tunables (offer expiry 72h, confirm window 48h, max items per side 5, max active trades 10, allowed types ["swap","sale"], reminder hours 12, expiry sweep 5min) stored in new `app_settings` table (Holder-editable via admin API). Extended `owned_attire` table with trade reservation support (no duplicate inventory table). Created 6 tables: app_settings, extended owned_attire (slot, reserved_trade_id, status now includes 'reserved'), item_ownership_history (audit trail), trades (proposer/recipient, type, state, confirmed_ats, expires_at), trade_items (many-to-many junction), trade_events (state transition audit). State machine: proposed→accepted/declined/cancelled/expired, accepted→cancelled/expired/completed (terminal: declined/cancelled/expired/completed). Items reserved ONLY on accept (not on propose). Both parties must confirm handoff before ownership moves. Accept cascades cancel to OTHER proposed trades with same items. Row locking with ID-ordered item locks (deadlock prevention). Dual audit trail (trade_events + audit_events). Lazy expiry (GET /trades calls expireStaleTrades). 10 endpoints under /trades: POST/ (propose), GET/ (list with role/state filters), GET/:id (detail, parties only get 404 not 403), POST/:id/accept (recipient only), POST/:id/decline, POST/:id/cancel (proposer for proposed, either for accepted), POST/:id/confirm (idempotent), GET/settings/trade (any logged-in user), GET/admin/settings (Holder only), PUT/admin/settings/:key (Holder only with audit logging). Authorization: Holder check `is_holder_verified=true AND verification_status='verified'`, non-party gets 404 for trade (not data leak). Validation: both users Holder-verified, ownership verified, item availability checked, limits from settings (no hard-coded 72/48/5/10/12), swap needs items both sides, sale needs items exactly one side (NO money fields), TOCTOU protected (accept re-validates under lock). Error codes: 400 ValidationError, 403 ForbiddenError, 404 TradeNotFoundError, 409 InvalidTransitionError. Migration 021 (RAN SUCCESSFULLY), migration 022 (documents rollback fix for 021). Created src/settings/settingsService.ts (cache TTL itself a setting, falls back to seeded defaults with warning), src/trades/tradeService.ts (650 lines, full state machine), src/trades/tradesRouter.ts (490 lines).
